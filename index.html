Four Studies in Convergence

Short fiction as an epistemic instrument — four crafts, one pattern.

These four stories were written on consecutive days, each set in a different craft, each written to test a single hypothesis: that fiction can discover things about its subject that analytical writing cannot reach. A potter cooling a kiln, a verger winding a cathedral clock, a man tending an inherited bonsai, a composer writing a fugue — each story asked what convergence looks like from inside a practice, and each returned a different answer: the eddy, the checking, the cycle, the toward.

Four patterns recurred in all four: convergence has a temporal dimension; it is visible only from the practitioner's perspective; it has a cost; and each domain names it in its own vocabulary. The afterwords — the laboratory notes recording what each story found — are withheld until the accompanying paper is published. The stories stand alone.
